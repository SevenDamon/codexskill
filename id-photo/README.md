# id-photo —— 证件照生成工具

按指定规格处理普通人像照片：**自动抠人像、换纯色底、按标准构图裁切、压到指定体积**。

## 这是什么

一个可用于 Codex / WorkBuddy 等 Agent 的 Skill（技能包）。装好后，你可以直接用自然语言让 AI 处理照片：

> "把这张照片做成学籍照，236×315 蓝底，60K 以内"

AI 会自动跑完整流程并交付成品。

## 安装

把 `id-photo` 整个文件夹放到 skills 目录：

| 平台 | 放置位置 |
|---|---|
| Codex 用户级 | `~/.codex/skills/id-photo/`（设置了 `CODEX_HOME` 时使用其下的 `skills/id-photo/`） |
| WorkBuddy 用户级 | `~/.workbuddy/skills/id-photo/` |
| WorkBuddy 项目级 | `<项目>/.workbuddy/skills/id-photo/` |

Windows 的 `~` 通常是 `C:\Users\<用户名>`。

放好后**重启对话**，若技能列表未刷新则重启客户端。Codex 安装命令见[仓库首页](../README.md#安装与调用)。本仓库统一使用技能名称 `id-photo`（原包为 `duan-id-photo-2026`）。

在 Codex 对话中输入：

```text
使用 $id-photo，把附件照片做成 236×315、RGB(67,142,219) 蓝底、JPG、60KB 以内的证件照，检查构图及实际文件大小。
```

## 环境要求

- **Python 3.10+**（含 pip）
- 依赖三个库：

```bash
python -m pip install numpy onnxruntime Pillow
```

- **抠图模型**：无需手动准备。首次运行时脚本会自动从镜像源下载 `u2net.onnx`（约 168MB）到 `~/.workbuddy/models/`。依次尝试 `hf-mirror.com` 和 Hugging Face；可用性及速度取决于网络。Codex 下仍沿用此缓存路径，也可用 `--model` 指定其他位置的模型文件。模型就绪后脚本在本机处理照片。

> 如果不希望自动下载，可手动下载后放到 `~/.workbuddy/models/u2net.onnx`。
> 注意校验文件大小 **≥150MB**——GitHub 源在国内常断连，下到的残缺文件会导致加载报错。

## 不用 AI 也能直接跑

这是个标准命令行工具，脱离 AI 也可独立使用：

```bash
cd id-photo/scripts

# 看有哪些规格
python idphoto.py --list

# 一寸蓝底
python idphoto.py --src photo.jpg --spec 一寸+蓝 --out out.jpg

# 一条命令出全套
python idphoto.py --src photo.jpg --spec "一寸+蓝,二寸+白,学籍照+淡蓝" --outdir ./out

# 要美白就加 --skin-gamma
python idphoto.py --src photo.jpg --spec 一寸+蓝 --out out.jpg --skin-gamma 0.86
```

### 规格 = 尺寸 × 底色（自由组合）

**尺寸**：一寸(236×315)、一寸标准(295×413)、小一寸、大一寸、二寸(413×579)、小二寸、学籍照(358×441)、学籍照大(390×480)、护照

**底色**：蓝、淡蓝、浅蓝、深蓝、白、红、深红、灰、透明

写法：`一寸+蓝`、`学籍照+淡蓝`、`二寸+白`、`1200x1600@67-142-219`

### 常用参数

| 参数 | 说明 |
|---|---|
| `--head-ratio` | 头高占画面比例，默认 0.65（标准 0.60~0.70） |
| `--top-space` | 头顶留白比例，默认 0.085 |
| `--gamma` | 整体提亮，默认 0.68（越小越亮） |
| `--skin-gamma` | 肤色美白，如 0.86；不传则不美白 |
| `--max-kb` | 体积上限，默认按尺寸自动推算 |
| `--transition-kill` | 深色短发+亮背景的发丛灰边处理，默认 60，**一般不用动** |
| `--debug 目录` | 保留中间产物，排查问题时用 |

## 规格与验收边界

内置“一寸”为 236×315，“一寸标准”为 295×413，“学籍照”为 358×441；这些名称不代表接收单位的统一标准，请优先提供明确像素、底色、格式和体积限制。工具不保证通过报名或证件审核。

`--max-kb` 是压缩目标，极小上限仍可能超限，输出后应实际检查文件大小。默认 `--gamma 0.68` 会整体提亮；若要关闭，显式传 `--gamma 1`。`--skin-gamma` 是另外的肤色美白选项。纯色底输出 JPEG，透明底输出 PNG，请使用对应扩展名。

## 重要提醒：有些照片不适合自动处理

**工具不是万能的**，遇到以下情况需要人工介入：

| 情况 | 说明 |
|---|---|
| **全身照** | 自动检测头肩会失败（把脚当脖子），需手工标定 |
| **长发/齐肩碎发** | 蓝底上头发边缘会有蓝晕，建议扎起头发重拍 |
| **背景有踢脚线/地板** | 背景色估计会被污染，需手工指定 |
| **侧脸/低头/遮挡** | 抠图质量显著下降，建议重拍 |

详见 `references/technique.md`（含实测数据与解决方案）。

**拍照要求**（想一次成功就照这个来）：
1. **上半身**入镜（不是全身）
2. 找**干净的纯色墙**做背景（白墙最好，别带踢脚线）
3. **自然光**充足，避免闪光灯
4. 离镜头约 **1.5 米**，用后置摄像头，由他人协助拍摄
5. **头发扎起来**，露出耳朵和额头
6. **上衣别与底色撞色**（蓝底忌蓝衣、白底忌白衣、红底忌红衣）
7. 看镜头，表情自然
